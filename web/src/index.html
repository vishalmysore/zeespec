How it is scored

      

        
Each task has one atomic spec, a reference implementation and a test that already passes. Hidden from the author:
          a correct implementation, a buggy one that breaks the spec but still passes the existing test, and a
          valid alternative that satisfies the spec but differs wherever the spec is silent (error messages, ordering, extra fields…).

        
A harness is faithful only if it rejects the buggy implementation and accepts both correct ones.
          Detection = buggy one rejected. False alarm = a correct one rejected.
